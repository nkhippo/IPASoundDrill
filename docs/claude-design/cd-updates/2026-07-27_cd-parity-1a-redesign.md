## CD-19【再設計】1a を「ヒーロー左＋振り返り右上／目的グリッド全幅」の2部構成に

### 背景（なぜ変えるか）
現行 CD/app の 1a は、左のサブコピー（タグライン直下）と右サイドバー「このアプリについて」が**同じ思想を二重に語って**いた。押し付けがましさの原因かつ横幅の無駄。**思想は一次を短く、詳細はモーダルへ集約**し、空いた横幅を機能（学習状況）に充てる。

### 変更後レイアウト
**PC（≥1024px）: 2行グリッド `grid-template-areas: "hero aside" / "purpose purpose"`（列 7fr : 3fr）**

- **hero（左上）**:
  1. タグライン「音を、美しく。」（明朝・大）
  2. **サブコピー（1文のみ）**＝思想の一次表現。例(ja): 「発音記号（IPA）で、英語の音をていねいに練り直す。読める音は、やがて聞き取れる音になります。」
  3. メタ属性（`6言語対応 · 無料 · 登録不要`）
  4. **「思想を読む →」テキストリンク**（accent 色）→ 既存「このアプリについて」モーダル（3h）を開く
- **aside（右上）**: 見出し「振り返る」＋ **学習状況カード**（旧・下部にあった progress カードを右上へ移動）。列幅いっぱい（`width:100%`）、`position:sticky; top:24px`。
- **purpose（全幅・2行目）**: 見出し「目的から選ぶ」＋ヒント＋**目的4カードを全幅グリッド**（`repeat(4,1fr)`）。hero と purpose の間は `border-top:1px solid hair` + `padding-top` で仕切る。

**削除するもの**:
- 右サイドバー「このアプリについて」パネル（`.top-sidebar` = title + 段落2つ + リンク）を**丸ごと撤去**。役割はサブコピー＋「思想を読む」リンク＋モーダルに集約。
- hero と purpose の間の独立セパレータ要素（`.top-section-sep`）は purpose ブロックの border-top に置換。

**SP（<1024px）: 単一カラム縦積み（DOM 順）**
1. タグライン → 2. サブコピー(1文) → 3. メタ → 4.「思想を読む →」→ 5. 目的4カード（縦積み。「目的から選ぶ」ラベルは SP では非表示のまま）→ 6.「振り返る」＋学習状況カード（最下部）。
※ 現行 SP と同じ「目的が先・振り返りが後」の順序を維持（学習状況を目的より上に出さない）。

### 目的（このカードが何を選ぶか）
- 第1カードの塗り強調なし＝**全4カード均等**（CD-17 を内包）。
- フッター言語導線は既に globe に一本化（CD-18 を内包。フッターは「IPAって何?」+ Feedback/Terms/Privacy/X のみ）。

### 位置の制約（Naoya 指示）
- **「目的から選ぶ」の位置は動かさない**（左に寄せ直さない／hero の下に置く）。全幅化はカード幅を広げる方向でのみ行う。

## CD-20【削除・重複導線の集約】ヘッダーの「学習状況 / IPAって何?」テキストリンクを撤去
- 対象: SP/PC `#1a*` ヘッダー（`.header-nav`）。
- 背景: 同一 destination への導線が複数存在していた。
  - **学習状況** = ヘッダーリンク ＋ 「振り返る」カード（= 2箇所）
  - **IPAって何?** = ヘッダーリンク ＋ フッターのピル（= 2箇所）
  - ※ ヘッダーのテキストリンクは元々 **PC トップのみ**表示（SP・他画面では非表示）。よって重複は実質「PC トップ限定」。
- 変更後: **ヘッダーのテキストリンク2本を撤去**し、各 destination を1箇所に集約:
  - 学習状況 → 「振り返る」カード（全幅で常時表示）のみ。
  - IPAって何? → フッターのピル（footer 表示の全画面で到達可）のみ。
  - 思想 → hero の「思想を読む →」（1a 内で1本）。
- 効果: ヘッダーが全ブレークポイント/全言語で同一（ブランド＋globe＋語彙≣＋ガイド?）になり、**「全画面・全言語で同じ UI」要件にも合致**。
- 他画面への影響: `.header-nav` は PC トップ限定要素で、in-play/vocab/profile 等では元々非表示。撤去による到達性の喪失なし（学習状況=カード / IPA=フッターで担保）。

## CD-21【移設】「IPAって何?」導線をフッター → hero へ(概念導線を hero に集約)
- 対象: SP/PC `#1a*` の hero テキストリンク群 と フッター。
- 背景: CD-20 で IPA をフッター一本にしたが、初訪問者に対しフッターのみは露出が弱い。概念を知る導線（思想／IPA）を hero にまとめる方針（Naoya 承認=案A）。
- 変更後:
  - hero に **「思想を読む →」＋「IPAって何? →」の2リンクを横並び**で配置（`.top-hero-links` コンテナ、accent 色・小サイズ）。
  - **フッターの「IPAって何?」ピルを撤去**（フッターは Feedback / Terms / Privacy / X のみ）。
  - 3e IPA 解説ページ自体は**温存**（両リンク・IPAリンクとも `navigate("ipa")`）。
- 結果の単一化: IPAって何?=hero のみ / 思想=hero のみ / 学習状況=カードのみ。全 destination が1箇所。
- 他画面: フッターからIPAピルが消えるが、IPA 概念導線はランディング(1a hero)に集約する設計判断。in-play ではフッター自体が非表示のため影響なし。

## 保持事項

- ヘッダーの globe（言語）・語彙(≣)・ガイド(?)・オンボーディング・他画面。
