## CD-19【再設計】1a を「ヒーロー左＋振り返り右上／目的グリッド全幅」の2部構成に

### 背景（なぜ変えるか）
現行 CD/app の 1a は、左のサブコピー（タグライン直下）と右サイドバー「このアプリについて」が**同じ思想を二重に語って**いた。押し付けがましさの原因かつ横幅の無駄。**思想は一次を短く、詳細はモーダルへ集約**し、空いた横幅を機能（学習状況）に充てる。

### 変更後レイアウト
**PC（≥1024px）: 2行グリッド `grid-template-areas: "hero aside" / "purpose purpose"`（列 7fr : 3fr）**

- **hero（左上）**:
  1. タグライン「音を、美しく。」（明朝・大）
  2. **サブコピー（1文のみ）**＝思想の一次表現。例(ja): 「発音記号（IPA）で、英語の音をていねいに練り直す。読める音は、やがて聞き取れる音になります。」
  3. メタ属性（`6言語対応 · 無料 · 登録不要`）
  4. **「思想を読む →」テキストリンク**（accent 色）→ 既存「このアプリについて」モーダル（3h）を開く
- **aside（右上）**: 見出し「振り返る」＋ **学習状況カード**（旧・下部にあった progress カードを右上へ移動）。列幅いっぱい（`width:100%`）、`position:sticky; top:24px`。
- **purpose（全幅・2行目）**: 見出し「目的から選ぶ」＋ヒント＋**目的4カードを全幅グリッド**（`repeat(4,1fr)`）。hero と purpose の間は `border-top:1px solid hair` + `padding-top` で仕切る。

**削除するもの**:
- 右サイドバー「このアプリについて」パネル（`.top-sidebar` = title + 段落2つ + リンク）を**丸ごと撤去**。役割はサブコピー＋「思想を読む」リンク＋モーダルに集約。
- hero と purpose の間の独立セパレータ要素（`.top-section-sep`）は purpose ブロックの border-top に置換。

**SP（<1024px）: 単一カラム縦積み（DOM 順）**
1. タグライン → 2. サブコピー(1文) → 3. メタ → 4.「思想を読む →」→ 5. 目的4カード（縦積み。「目的から選ぶ」ラベルは SP では非表示のまま）→ 6.「振り返る」＋学習状況カード（最下部）。
※ 現行 SP と同じ「目的が先・振り返りが後」の順序を維持（学習状況を目的より上に出さない）。

### 目的（このカードが何を選ぶか）
- 第1カードの塗り強調なし＝**全4カード均等**（CD-17 を内包）。
- フッター言語導線は既に globe に一本化（CD-18 を内包。フッターは「IPAって何?」+ Feedback/Terms/Privacy/X のみ）。

### 位置の制約（Naoya 指示）
- **「目的から選ぶ」の位置は動かさない**（左に寄せ直さない／hero の下に置く）。全幅化はカード幅を広げる方向でのみ行う。

## 保持事項
- Design System トークン・タグライン文言・目的カードのアイコン/文言。
- ヘッダー（progress/IPA リンク・globe）・オンボーディング・他画面。

## 適用後の確認
- 右サイドバー「このアプリについて」が消え、代わりに「思想を読む →」リンク1本。
- 学習状況カードが hero の右上、目的4カードが全幅・均等。
- 「目的から選ぶ」が hero の直下に残る（左寄せ移動していない）。
- SP は 目的カード→振り返り の順で縦積み。
- エクスポート後、repo CD を差分突合（意図外変更 0）で同期。
