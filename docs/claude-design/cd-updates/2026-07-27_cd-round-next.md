## 3. B-1/B-2【答えペイン: respell 主役でクリーン化】(2a-pc / 2b-pc の右ペイン)
右ペイン（panel 地）を**枠付きサブカードの縦スタック**に整理（白地の羅列をやめる）。順序:
1. **正解/不正解バッジ**（teal 丸＋チェック「正解」／不正解時は accent 丸＋「おしい」等）。
2. **(2b のみ)「あなたの解答」**: ユーザーが組んだ IPA を `/ ˈdʒæk /` で1行（**未入力で確認した人向けに、入力が無ければこの行は出さず正解に直行**）。
3. **正解**: 2a=単語（jacket, 明朝 40px）＋訳（上着…）。2b=正解 IPA（大, 中央, 強勢母音に下線）。
4. **★respell（主役）**: `発音（よみ）` ラベル＋大きめで **JA-kuht**（RP と異なれば GA/RP 2 段: GA `JA-kuht` / RP `JA-kit`）。IPA が読めない層の主導線。
5. **発音カード（枠付き・地 paper）**: `発音（🔊で再生）` ラベル。GA 行（/ ˈdʒækət / ＋丸スピーカー）／RP 行（同）。**GA=RP が実質同一なら1行＋「GA=RP」バッジ**（重複 RP 行を出さない）。差分がある時は下に **理由別の具体文**（例: 弱母音が違う `ə↔ɪ` / R の有無 / 「あ」の質 など。`ga_rp_same_reason` 由来）。
6. **発音ポイント（枠付き・条件表示）**: 綴り規則（`pattern` がある語のみ, 例「y → /aɪ/」）＋**要注意音は本当に難しい1〜2音のみ**（例「s」。全列挙しない）。両方空なら**枠ごと非表示**。schwa 単独注意は出さない。
7. **覚えた n/3**（枠付き行, チェック 3 スロット）。
8. `つぎへ →`（**teal** ボタン、黒にしない）。
- placeholder 例（jacket, GA≠RP weak_vowel）: あなたの解答 `/ˈdʒæk/` → 正解 `ˈdʒækət` → respell `JA-kuht / JA-kit` → GA `/ˈdʒækət/`・RP `/ˈdʒækɪt/`＋「弱母音が違う ə↔ɪ」→ 発音ポイント「要注意音: s」。
- placeholder 例（spy, GA=RP）: respell `SPY` → 発音カードは1行`/spaɪ/`＋「GA=RP」→ 発音ポイント「綴り規則: y → /aɪ/」。
