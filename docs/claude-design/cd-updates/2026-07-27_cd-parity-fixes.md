## 4. 修正項目(section ID / 粒度 / 仕様)

### CD-1【削除】1a「目的から選ぶ」ラベル+説明文
- 対象: SP `#1a-ja` `#1a-en` `#1a-ko` / PC `#1a-pc` `#1a-pc-en` `#1a-pc-ko`
- 内容: purpose カード群の直上の「目的から選ぶ / 目的をひとつ選ぶと、その場ではじまります。」(各言語相当)を **削除**。カードは「無料 · 登録不要」等のメタ行の直後に置く。

### CD-2【削除】デバイスフレーム装飾(9:41 / ●●●)
- 対象: **SP 全フレーム**(`#1a-*` `#2a`〜`#2d` `#3a`〜`#3g`)/ **PC 全フレーム**(`#1a-pc*` `#2a-pc`〜`#2d-pc` `#3a-pc`〜`#3g-pc`)
- 内容: 各モック上部の `9:41` ステータスバー行と右上/左上の `●●●`(点)を **削除**。これは実UIではないため、モックからも除去して実装の誤踏襲を断つ。
- 影響範囲: §5 参照(全フレーム)

### CD-3【意匠変更】SRS マーキングを縦→横・手動表現に統一
- 対象: SP `#3g`(オンボ スライド3「覚えたら、自分でチェック」)
- 内容: ☑️/□ の並びを **横3ボックス**に変更(実態=答え合わせ 2a–2d と同じ横並び)。手動でタップして印を付ける体で描く(自動採点で増減しない)。
- 確認のみ(変更不要): 語彙リスト `#3b` `#3b-pc` に SRS マーキングが **無い**ことを維持(CD は既に正)。

### CD-4【意匠変更】モーダル背景を純白へ
- 対象: モーダルを持つ全 CD セクション(SP `#3g` オンボ / PC `#3g-pc` / 他モーダル表現があれば全て)
- 内容: モーダル card 背景を **#FFFFFF** に。オーバーレイ・角丸・影は現状維持。

### CD-5【要素追加】3e「IPA って何？」への SP 導線(フッター)
- 対象: SP `#1a-ja` `#1a-en` `#1a-ko` のフッター(Feedback / Terms / Privacy / X の並び)
- 内容: フッターに「**IPA って何？**」(各言語相当)リンクを **追加**し、`#3e` へ遷移する導線とする。PC は既存ヘッダーに「IPA って何？」があるため **追加不要(保持)**。

### CD-6【要素追加】3f 言語設定の SP 専用ページ + 導線
- 対象: SP。新規フレーム `#3f`(SP 版 言語設定=表示言語のみ)を PC `#3f`(言語設定・表示言語のみ)に準拠して新設。
- 導線: SP フッター(CD-5 と同じフッター)に「言語設定」導線を追加、または既存 `JA▾` からフルページへ入れる形。**どちらの導線にするかは Claude Design 上で 1 案作成し、Naoya 確認**。
- 内容: 表示言語(ja/en/ko/zh-Hans/zh-Hant/fil)選択のみのシンプルなページ。学習発音(GA/RP)設定は含めない(それは 3a プロフィール)。

## 5. 影響範囲チェック(cross-screen)

- **CD-2(フレーム装飾)**: SP 全フレーム + PC 全フレーム = 全モック。1つも残さない。
- **CD-4(モーダル)**: オンボ(SP 3g / PC 3g-pc)+ 他モーダル表現全て。
- **CD-5(フッター)**: SP 1a の 3 言語すべて。
- **CD-3(SRS)**: SP 3g のみ(答え合わせ表現が別途あればそちらも横で一貫)。

## 6. 多言語対応方針

- 既定どおり **ja / en / ko**(CD 現存言語)を対象。
- CD-1 / CD-5 / CD-6 は 3 言語すべてに適用。zh-Hans / zh-Hant / fil は CD セクションが無いため触らない。
