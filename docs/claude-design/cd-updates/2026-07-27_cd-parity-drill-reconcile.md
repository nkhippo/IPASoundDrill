# CD 修正指示書 — ドリル(2a/2b)を「実UIと完全一致」できる正本へ整える(2026-07-27)

- メタ: **CD 修正(CD 側を先に直す)** / 規模: **大**(ドリルの骨格)
- 対象: `docs/claude-design/pc.dc.html` の `#2a-pc` / `#2b-pc`(および SP `sp.dc.html` の対応フレーム)
- 背景: Naoya 指摘「2b の CD と実UIが全然違う。語彙リスト・各問題含め CD と完全一致させたい」。調査の結果、**CD 側にも実装機能を表現しきれていない箇所**(二重母音キー・削除操作・未回答状態)があり、単純な app→CD コピーでは一致させられない。governance(実質的意匠は CD で)に沿って **CD を先に正本化** → その後 app を CD に合わせる。
- 進め方: 本書の (A)(B) を Naoya が Claude Design で反映 → エクスポート → repo CD 同期 → **その後** ClaudeCode が app を CD に合わせて実装。

---

## 判断: なぜ CD を先に直すか
2b の CD↔app 差分は「純粋な削除」ではなく**構造・内容の実質差**(キーボードのグループ構成 / 入力ボックス / ボタン配置 / 答えペインの内容)。governance 上 CD が正本なので、まず CD を**実機能を満たす形**に更新し、単一の到達目標を確定してから実装するのが最短かつ手戻りが少ない。

---

## 現状の CD(2a-pc / 2b-pc)= 目標として採用する骨格
以下は **CD が優れており、app が CD に合わせるべき**部分(CD 変更不要):

1. **統合カード枠**: ドリル全体を 1 枚の角丸カード(`width:1024px; background:paper; border:1px hair; border-radius:20px; overflow:hidden`)に収める。→ app は現状ヘッダーとペインがバラバラで、左ペインが紙背景と同化する不具合がある。**カード枠+ヘッダー内包**にすれば同化・左端見切れが解消。
2. **ヘッダーをカード内**に: 戻る(38px 丸)+ タイトル+進捗メーター(max 420px)+ GA バッジ(globe+GA)+ カウンタ(mono)。下辺 hair。
3. **本文 2 カラム**: `grid-template-columns:1fr 1fr`。左=出題(padding 44/40, border-right hair, 地=paper)、右=答え(padding 44/40, 地=panel)。→ 地色は「紙カードの中の paper|panel」なのでページ背景とは同化しない。
4. **右(答え)ペインの型**: `正解` バッジ(teal 丸+チェック)→ (2b は「あなたの解答」)→ 解答 IPA →「発音（🔊で再生）」カード(GA 行 / RP 行、各行に丸スピーカー、下線=強勢母音)→ 差分ヒント(例「弱母音が違う ə↔ɪ」)→「覚えた n/3」チェック → `つぎへ →`(**teal** ボタン)。
5. **入力ボックス**: 2a=「単語を入力…」(signal 枠/panel 地)、2b=組み立て中の IPA を表示(signal 枠/signal-soft 地、強勢母音に下線、キャレット)。
6. **左下ボタン**: 2a=`確認する`(teal 単独)、2b=`クリア`(1) + `確認する`(2) の横並び。

> app 側の是正点(実装時): 「正解/不正解」バッジ新設・`次へ`(黒)→`つぎへ →`(teal)・答えペインを GA/RP 発音カード型へ・ヘッダーとペインを 1 枚カードに統合・左ペイン地=paper。

## (A) CD に **追加・修正**が必要(実機能を表現できていない)

### A-1【追加】二重母音 Diphthongs グループ
- 現状 CD の母音行は単母音のみ(i ɪ ɛ æ ə ʌ ɑ ɔ ʊ u)。**二重母音キーが無く /spaɪ/ 等が組み立て不能**。
- 変更: **「Diphthongs · 二重母音」グループを追加**(Vowels と R-colored の間 or Consonants の前)。キー: **eɪ / aɪ / ɔɪ / oʊ / aʊ**(GA 基準。RP セッション時の出し分けは実装準拠)。スタイルは他キーと同一(40px, hair 枠, panel 地)。

### A-2【定義】削除(バックスペース)操作
- 現状 CD には削除手段が無い(実 app は各行末に ⌫ キー)。CD に削除の型を明示したい。
- 推奨: **各グループ末尾の ⌫ は冗長**。入力ボックス右端に **⌫ を 1 つ**(または「1 つ戻す」)を置く型に統一し、キーボード各行からは ⌫ を除く。→ 実装もこれに合わせて per-row ⌫ を廃止。
  - ※ Naoya 判断: 「入力ボックス右に ⌫ 1 つ」で良いか、現行の per-row ⌫ を CD 側に描き足すか。**推奨=入力ボックス右に 1 つ**。

### A-3【追加】未回答(確認前)の状態フレーム
- 現状 CD は**回答後の 2 ペインのみ**。実 app の「1 問目」は右ペインが無く、出題カードが**横いっぱい**に見える(Naoya 指摘)。
- 追加してほしい CD フレーム(`2a-pc-empty` / `2b-pc-empty` 等):
  - 統合カードは同じ 1024px 枠。**確認前は単カラム(出題のみ)で中央 ~560px に絞る**(横いっぱいにしない)。ヘッダー(進捗バー)はカード上辺で全幅のまま。
  - 2b はこの状態でキーボード+入力ボックス+クリア/確認するを表示(右ペインはまだ出さない)。
  - `確認する`押下で 2 ペイン(既存 2a-pc/2b-pc)へ展開。
  - 狙い: 「未回答=集中した単カラム、回答後=2 ペインで比較」。app の「半分にして/左端見切れ」を構造的に解消。

## (B) 答えペインの内容 — 【決定済 2026-07-27】

### B-1 内容: GA/RP 発音カード ＋ 発音ポイント を **両立**(確定)
- Naoya 決定: 「**現 app どおり GA/RP カード＋発音ポイントを載せる。要素は問題ない**」。
- → CD 側に **発音ポイント(綴り規則・要注意音 + 音チップ)ブロックを追加**(GA/RP 発音カードの下)。

### B-2【最重要】“情報が雑多で白背景にダサく見える”を解消(CD のクリーンな型に一致)
- Naoya 指摘: 「要素は良いが、**Claude Design と比べて実 app の答えペインがダサい**。おそらく**白背景に情報が雑多に羅列**されているから。完全一致させたい」。
- 原因: 実 app は 単語/訳/答えを確認/IPA/スピーカー/RP 注記/発音ポイント/覚えた/次へ を**フラットな白地に列挙**。CD は各情報を**枠付きサブカード＋余白**で構造化している。
- 方針(= app を CD の型に一致):
  1. **正解/不正解バッジ**(teal 丸+チェック)を先頭に。
  2. 解答語は **中央・明朝 大**、訳は下に muted 小。
  3. **「発音（🔊で再生）」は枠付きサブカード**(border hair / 地 paper / radius 16)にまとめ、GA 行・RP 行(各行に丸スピーカー)＋差分ヒント。
  4. その下に **「発音ポイント」も同じ枠付きサブカード**で1ブロック(綴り規則・要注意音チップ)。
  5. 「覚えた n/3」も枠付き行、`つぎへ →`(teal)。
  6. 余白(padding 44/40)・区切り(hair)・地色(右ペイン=panel)を CD どおりに。
- 進め方: governance に沿い **CD を正本に**(CD に発音ポイントのサブカードを描き足す=B-1)。app はその CD に一致実装。「Claude が先に直して CD に反映」でも可だが、CD が既にクリーンなので **CD 追記 → app 一致**が最短。
