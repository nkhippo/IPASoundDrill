## 【2】B-1/B-2 答えペインを respell 主役で再構成（2a-pc / 2b-pc の右ペイン）
白地に情報を羅列せず、**枠付きサブカードの縦スタック**にする。上から:
1. **正解/不正解バッジ** — teal 丸＋チェック「正解」／不正解時は accent 丸＋「おしい」。
2. **（2b-pc のみ）あなたの解答** — ユーザーが組んだ IPA を1行 `/ ˈdʒæk /`（薄字ラベル「あなたの解答」）。※未入力で確認した人向けに、入力が無ければこの行は出さず正解に直行。
3. **正解** — 2a=単語 `jacket`（明朝40px・中央）＋訳（上着・ジャケット, muted）。2b=正解 IPA `ˈdʒækət`（38px・中央・強勢母音に stress 下線）。
4. **★読み方（respell・主役）** — 薄字ラベル「読み方」＋大きめ（20–24px）で `JA-kuht`。**GA と RP で異なる時は2段**（GA: `JA-kuht` / RP: `JA-kit`）。IPA が読めない層の主導線なので目立たせる。
5. **発音カード（枠付き・地 paper・radius16）** — ラベル「発音（🔊で再生）」。GA 行 `/ ˈdʒækət /`＋丸スピーカー、RP 行 `/ ˈdʒækɪt /`＋丸スピーカー。**GA=RP が実質同一なら1行のみ＋「GA=RP」バッジ**（同じ IPA を2回出さない）。差分がある時は下に理由の一言（例「弱母音が違う ə↔ɪ」「GA は語末 r を発音」など）。
6. **発音ポイント（枠付き・条件表示）** — 綴り規則（ある語のみ, 例「綴り規則: y → /aɪ/」）＋要注意音（**最大2音**, 例「要注意音: s ɔ」）。**両方空なら枠ごと非表示**。schwa 単独注意は出さない。
7. **覚えた n/3** — 枠付き行＋チェック3スロット。
8. **`つぎへ →`** — teal ボタン（黒にしない）。

**placeholder 例（そのまま使ってよい）**
- jacket（GA≠RP）: あなたの解答 `/ˈdʒæk/` → 正解 `ˈdʒækət` → 読み方 GA `JA-kuht` / RP `JA-kit` → 発音カード GA `/ˈdʒækət/`・RP `/ˈdʒækɪt/`＋「弱母音が違う ə↔ɪ」→ 発音ポイント「要注意音: s」。
- spy（GA=RP）: 正解 `spaɪ` → 読み方 `SPY` → 発音カード1行 `/spaɪ/`＋「GA=RP」→ 発音ポイント「綴り規則: y → /aɪ/」。
