## 【2】答えペイン（respell 撤去・IPA は GA/RP 発音カードに一本化）
右ペイン（`--panel` 地）を**枠付きサブカードの縦スタック**にする。上から:
1. **正解/不正解バッジ** — 正解=teal 丸＋チェック「正解」／不正解=accent 丸＋「**不正解**」（※旧「おしい」から変更済）。
2. **あなた: {入力}** — muted ラベル＋入力文字（正誤色）。
3. **正解語** — 2a=単語（例 `retired`、大・正解色）＋訳（退職した, muted）。2b=正解 IPA（大・中央・強勢母音に stress 下線）。
4. **発音カード（枠付き・地 paper・radius16）** — ラベル「発音（🔊で再生）」。**GA 行**（`GA` バッジ＋`/rɪˈtaɪrd/`＋丸スピーカー）／**RP 行**（`RP` バッジ＋`/rɪˈtaɪəd/`＋丸スピーカー）。強勢母音に stress 下線。**GA=RP が実質同一なら 1 行＋「GA=RP」バッジ**（同一 IPA を2回出さない）。→ **これが唯一の IPA 表示**（respell・辞書表記・曖昧メイン IPA は出さない）。
5. **発音ポイント（枠付き・条件表示）** — 「第2音節を強く（2音節）· 要注意音: rɪ」＋要注意音チップ（signal-soft）。綴り規則（`pattern` がある語のみ）。**空なら枠ごと非表示**。schwa 単独注意は出さない。
6. **覚えた n/3**（枠付き行＋チェック 3 スロット, muted ラベル「覚えたらタップ」）。
7. **`次へ →`** — teal ボタン（黒にしない）。

**placeholder 例（そのまま可）**: retired → 正解 `retired`／退職した → 発音カード GA `/rɪˈtaɪrd/`・RP `/rɪˈtaɪəd/`（2行）→ 発音ポイント「第2音節を強く · 要注意音: r ɪ」。

## 【4】語彙リスト 3b（キーボード常時表示・カード統一・GA/RP モード分離）
- **記号ピッカー（別ページ/モーダル）は廃止** → フィルタカードに **IPA キーボードを常時表示**（横1行スクロール）。
- **単語カード統一**: 語＋CEFR バッジ（色）＋品詞＋意味＋**GA 行 / RP 行**（`GA`/`RP` バッジ＋IPA＋丸スピーカー、GA=RP は RP 行に「（同じ）」）。3×3 チェックドット・単語/フレーズタブ・CEFR ピルは無し。
- **★GA/RP モード分離（本セッション新規, develop `4a84db6`）**:
  - フィルタ頭右に **GA / RP セグメント切替**（`.vocab-accent-toggle`: hair 枠・panel 地・font-mono ラベル、選択側 = signal 文字＋panel 地＋影）。
  - **GA モード** = キーボードは GA 記号セット（i ɛ ɝ ɚ ʌ u ɔ ɑ oʊ …）／各語の **GA IPA(`c.ipa`) のみ**で絞り込み。
  - **RP モード** = キーボードは RP 記号セット（iː e ɜː ɔː ɑː ɒ əʊ ɪə eə ʊə …）／**RP IPA(`c.rp_ipa`) のみ**で絞り込み。
  - キーボード上のラベル = 「{GA|RP} の発音記号で絞り込み」（アクセント別）。件数行 = 「… を含む {GA|RP} 発音 · N件」。
  - **絞り込み中の記号強調**は**アクティブアクセントの行のみ**に付く（既存デザインルール `.ipa-match` = signal 太字）。例: GA モードで `ɛ` → 各ヒット語の **GA 行の ɛ が signal 強調**、RP 行（`e` 表記）は非強調 → GA↔RP の綴り差（ɛ↔e, ɝ↔ɜː, ɑ↔ɒ, oʊ↔əʊ …）が視覚化される。
  - アクセント切替時、選択中の記号チップは**クリア**（記号セットが変わり幽霊フィルタになるため）。
  - **PC は 2 カラム / モバイルは 1 カラム**（レスポンシブ）。
  - > データ根拠: ɛ/ɝ/ɚ/oʊ は GA のみ、iː/ɜː/ɔː/ɑː/ɒ/əʊ/eə は RP のみに出現（wordlist 5397 語実測）。旧「両方検索」方式では GA モードで RP 固有記号を絞り込めない欠陥があり、本分離で解消。
