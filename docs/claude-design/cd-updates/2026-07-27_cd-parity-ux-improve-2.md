## CD-14【統一】戻るボタン＝丸chevron / オーバーレイ見出し＝左寄せ明朝
- 対象フレーム: **学習状況 3d / 記号ピッカー 3c / 学習プロフィール 3a**（SP・PC 該当）。
- 現状 CD: 3d/3c は「枠つき pill＋テキスト『戻る』＋中央見出し」、3a は「← テキストリンク」。
- 変更後: **語彙リスト 3b / IPA解説 3e / 言語設定 3f と同じパターンに統一**：
  - 戻る = **34px 丸ボタン（panel 背景・hair border・muted の chevron `‹` アイコンのみ、テキストなし）**。
  - 見出し = **左寄せ・明朝（Noto Serif JP）**（中央寄せ・ゴシックをやめる）。
- 目的: 全画面で戻る操作と見出しの型を揃える（ヘッダー3ボタン globe 統一 CD-10 と同じ意図の横展開）。

## CD-15【簡潔化】ドリルヘッダーのアクセント表記「GA · 米 / RP · 英」→「GA / RP」
- 対象: ドリル 2a–2d（SP・PC、集約ヘッダー行のアクセントバッジ）。
- 現状 CD: 「GA · 米」「RP · 英」（globe アイコン + 国名漢字付き）。
- 変更後: **「GA」「RP」のみ**（`· 米 / · 英` を削除）。globe アイコンの有無は CD 現状踏襲でよいが、テキストは短縮。
- 根拠: Design System「国旗なし」方針と整合し、ヘッダーをより簡潔に（Naoya 指摘）。

## CD-16【一本化】オンボーディング（3g）の位置表示をドットに統一
- 対象: オンボーディング 3g（SP スライダー）。
- 現状 CD: 上部「ガイド N / 4」＋下部ドット（••••）の**二重表示**。
- 変更後: **位置はドットのみ**で示し、上部ラベルは **「ガイド」**（番号 `N / 4` を削除）。
- 根拠: 位置指標の重複を排除。ドットはボタン近傍で位置を示し、標準的なカルーセル表現。
