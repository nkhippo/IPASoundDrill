## CD-9【削除】1a 等の装飾アンダーバー(`.top-swash` 相当)
- 対象: SP `#1a-*`(見出し「音を、美しく。」直上)/ `#3e`(見出し直上)/ PC 対応フレーム。該当の `<span style="...width:30px;height:2px;background:var(--accent)...margin-bottom:18px"></span>`。
- 内容: **削除**。削除で生じる上余白は見出しの上マージン/カード padding に吸収(app は `.top-swash{display:none}` で対応、余白は既存 padding で自然に詰まる)。
- 根拠: 装飾の意図が伝わらず、単独の線として誤読される(Naoya 指摘)。

## CD-10【変更】1a ヘッダー3ボタンを丸型統一 + 言語ボタンを globe アイコン化
- 対象: SP `#1a-*` / PC `#1a-pc*` のヘッダー右側 3 コントロール。
- 現状 CD: 言語 = 「JA ▾」等のテキスト pill / 語彙(≣)・ガイド(?) = 丸。
- 変更後: **3 つとも同一の丸ボタン(34px 円、hair border、panel 背景)**。言語ボタンは **globe(地球)アイコン**(円+経線)にし、言語コードテキスト(JA/EN)は表示しない。現在言語は展開メニュー/言語設定ページで示す。
- 補足: **表示言語のデフォルトは英語**(app は `LANG` fallback = `en` で既に既定 en)。CD モックも既定表示を EN 前提に。

## CD-11【削除】ドリル(2a-2d)ヘッダーの語彙リスト(≣)ボタン
- 対象: SP `#2a`〜`#2d`(card 上部の集約ヘッダー行)。CD では戻る+title+meter+counter の下段等に語彙リスト(≣)アイコンボタンがある。
- 内容: **語彙(≣)ボタンを削除**。**GA/RP 表示(アクセント)は保持**。
- 根拠: 問題を解く最中に語彙リストへ飛ぶ導線は不要(Naoya 指摘)。GA/RP の別は表示があってよい。
