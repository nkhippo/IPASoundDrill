設計判断まとめ

対話で確定した仕様と、その理由

各画面 UI の背景にある意思決定を集約。実装・引き継ぎ時の判断根拠として参照してください。

マーキング（覚えた）
◆ユーザーが手動でチェック — 正誤で自動評価しない。習得の主観判断はユーザーに委ねる。
◆最大3回で卒業 — チェックの少ない語から優先出題。
◆目的ごとに独立 — 4目的で別管理。
◆Local Storage 管理 — 端末内に保存。アカウント不要。
判定・アクセント
◆完全一致判定 — 惜しさ・部分正解は示さない。
◆GA / RP はセッション共通 — プロフィール (3a) で選択、学習中は切替不可。各ドリルカード左上に subtle badge。
◆語彙リストは両表記 — 辞書 (3b) は GA/RP 双方を個別スピーカーで再生。
レベル・構造
◆CEFR は単語ごと — 各カードに「語彙」タグ。プロフィールで複数レベル選択。
◆既定 A1＋A2 — 初級を既定に。
◆目的ファースト — 「詳しい設定」は top から撤去。1タップ開始。
◆絞り込みはインライン — 各ドリル画面内の静かなチップ。独立画面なし。
入場・オンボーディング
◆プロフィール一元通過 — 3a に集約。毎セッション通過。
◆LS プリセット — 前回設定を初期値に。「そのままでいいか」の1判断のみ。
◆初回オンボーディング — 4スライド自動発火。スキップも完了扱い。以降 1a から直接開始。
各ドリルの要点
◆2a 音の発音を確かめる — IPA を見て正しい読みを確認。
◆2b 発音から書いてみる — 綴りから IPA をキーボードで組み立てる。
◆2c 音から単語を覚える — 音声＋IPAヒントから単語を思い出す。
◆2d 連結する音に慣れる — 文脈中のフレーズを聞き取る。音声はフレーズのみ。
