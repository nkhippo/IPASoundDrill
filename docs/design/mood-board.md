## 目的

Naoya さんの脳内にある **視覚方向性 (Aesthetic Direction)** を言語化し、参照リンク集として蓄積。Claude Design が "音アプリらしい" 見た目にするために、テキストだけでは伝わりにくい "気配" を、参照リンクで補う。

## このドキュメントの位置づけ

- **性質**: **Naoya さん主導**。Claude が骨格 + 各カテゴリに初期候補を数個提示、Naoya さんが実感で追加・削除・優先順位付け
- **完成度目標**: Phase 1 起動前に、5 カテゴリそれぞれに 5-10 個の references
- **参照される場面**:
  - Claude Design ブリーフの §9 "References"
  - Naoya さん自身が Claude Design と "美意識の言語" を共有するとき
  - Cluster 2 (視覚言語刷新) の初期方向性議論

## 記載フォーマット

各 reference には以下を書く:

- **タイトル** (URL があれば hyperlink)
- **カテゴリ**: どのカテゴリの参照か
- **なぜ**: なぜこれを参照するのか (1-2 文)
- **どの側面**: 色 / タイポグラフィ / レイアウト / 動き / トーン / 全体感 のどれ

**例**:

> [Notion](https://www.notion.so) — 静けさ / 全体感 / タイポグラフィ
>
> なぜ: 灰色トーンの静けさと、情報密度の高さの両立。原則 6 (1 画面 1 主軸) と親和性

## 参照の使い方 (Claude Design での)

### Claude Design ブリーフでの参照

```
## 9. References

mood-board.md の主要参照:
- Notion 的な静けさ (カテゴリ 1)
- 坂本龍一 async のジャケット (カテゴリ 2、色の抑制と音象徴)
- Charis SIL フォント (カテゴリ 3、IPA タイポグラフィ)

反面教師:
- Duolingo (mood-board.md カテゴリ 4)
- Anki の色気のなさ (機能は学ぶが見た目は避ける)
```

### Naoya さん自身が Claude Design と対話するとき

Claude Design にプロトタイプを見せて "これは違う" と感じたとき、mood-board.md の該当参照を示すことで、"どこがどう違うか" を言語化できる。

例:
> このプロトタイプは Duolingo に近づきすぎ (カテゴリ 4)。mood-board.md カテゴリ 1 の Notion / Kinfolk 方向にシフトして。

## Naoya さんへの依頼 (このドキュメントを完成させる)

1. **各カテゴリの空白を埋める**: 実感で "これは自分の中の IPA Sound Drill" と感じる参照を追加
2. **Claude 初期候補の評価**: 「これは違う」「これは的確」を判断、違うものは削除
3. **優先度付け**: 各カテゴリで "特に重要な参照 top 3" をマーク
4. **Screenshots / Images の扱い**:
   - 現状はテキスト + URL のみ
   - 必要なら Naoya さんが Obsidian 側で画像を貼り付け (Vault MCP は画像非対応の可能性)
5. **新カテゴリの追加**: 上記 6 カテゴリで漏れがある場合、追加 (例: "Web デザインの参照", "アプリ UI の参照" 等)

## 参照の集め方 (Tips)

- **Pinterest / Are.na / Instagram Save**: Naoya さんが日常的に "美しい" と感じたものを蓄積している場所があれば、そこから引用
- **Screenshots**: プロダクトを触ったときに "この画面が好き" と感じた瞬間の screenshot を残す
- **Books**: 参考にした書物 (菊地信義の装丁論、坂本龍一のインタビュー等) の書誌情報
- **Films / Music**: 視覚参照だけでなく、聴覚参照 (プロダクトの声 = 静けさ) の参考も可
