# 3h このアプリについて

索引: `docs/features/README.md`。モーダル一覧は `docs/features/_common.md`。

## 観測可能挙動

- `1a` トップページ Hero の `#topSidebarLink`「思想を読む」タップ → `openAboutModal()` → `#aboutModal` を表示（2026-07-28: フッター常時 DOM 配置から Hero 起動のモーダルへ変更）
- 閉じるボタン（`#aboutModalClose`）または `#aboutModalScrim` クリックで `closeAboutModal()`
- リード、「なぜ IPA を学ぶか」、特徴 5 項目、フィードバック導線で構成する

## 画面構造

`#aboutModal`（`role="dialog"`）内に `#aboutBlock`（`data-frame="3h"`）を配置。DOM は常時存在するが**既定で `hidden`**（開くまで非表示。旧仕様の「フッター常時可視 DOM」ではない。AI クローラビリティは DOM 常在のみで担保）。IPA 表記は `--font-ipa`、その他は Mood B token を使用する。
