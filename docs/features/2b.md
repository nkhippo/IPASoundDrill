# 2b 発音から書いてみる（Encode）

索引: `docs/features/README.md`。共通シェル・セッションフロー・適応出題・出題フィルタ定数は `docs/features/_common.md`。

## 観測可能挙動

- 目的: 既知語を見て、IPA（強勢含む）を組み立てられる力を鍛える
- 入口は英単語。IPA キーボードはプロフィール固定アクセントに追従
- 音素フォーカス（主）・綴りタイプ（従）でフィルタ（定数は `docs/features/_common.md` 出題フィルタ共通定数、`2a` と共通）
- 適応出題は `2a` と共通ロジック（`docs/features/_common.md`）

## 画面構造

`#cardEncode`

| 要素 | 内容 |
|------|------|
| `.qno` | 出題番号 |
| Progress meter | `#eProgress` |
| CEFR タグ | STEP 行右上 |

| IPA ビルド | `.build`（タップ組み立て）+ キーボード（固定アクセントの記号セット） |
| Check / Clear | 判定・クリア |

## 採点則・定数

| ok | bad |
|----|-----|
| IPA（強勢含む）完全一致 | それ以外 |

旧「強勢以外一致 = near」判定は削除済み。強勢込み完全一致のみ ok。Encode の LCS トークン色分けはフィードバック用（判定自体は 2 値のまま）。
