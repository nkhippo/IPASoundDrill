# 2c 音から単語を覚える（Study）

索引: `docs/features/README.md`。共通シェル・セッションフロー・先読み/終了は `docs/features/_common.md`。

## 観測可能挙動

- 目的: 音から単語の意味（と綴り）を覚える。入口は必ず音（sound-first）
- ループ: TTS 自動再生 → IPA のみ提示 → 「意味を確認する」→ 単語＋gloss（2 段階 reveal）。採点なし
- Quiz（MCQ / ディクテーション）は凍結（`MODEB_QUIZ_ENABLED=false`）。コード温存・UI 非表示（Study-only）
- プール除外: `letter` / `contraction`。CEFR はプロフィール複数選択で横断フィルタ（Band 自動解放は廃止済み）
- 出題: フィルタ後プールの全語を Study として重複なしで消化（先読み・終了は `docs/features/_common.md`）

## 採点則・定数

Study は採点なし（正誤判定を行わない。ユーザー手動マーキングのみ）。

- Quiz 復活時の distractor（凍結中は不使用）: 音素近傍語中心（`neighbors`、近傍 2 ＋同 CEFR ランダム 1）
- セッション定数（Quiz 有効時・温存）: `MODEB_SESSION = {newCount: 10, reviewCount: 10}`
- `MODEB_BANDS` は CEFR 許可リストとして残置（Band Unlock 機構自体は廃止済み）
