# 2d 連結する音に慣れる（Connected Speech）

索引: `docs/features/README.md`。共通シェル・セッションフローは `docs/features/_common.md`。

## 観測可能挙動

- 連結句（201 句）: linking / assimilation / elision。Decode のみ。Level L1–L3。キャリア文に IPA 埋め込み。TTS は GA 固定
- 弱形（36 語）: 高頻度機能語の弱形。Decode のみ。TTS は `?weak=`（GA/RP）
- CEFR は word-level タグ表示のみ。UI フィルタは Type / Level の 2 軸のみ（CEFR フィルタは追加しない）
- 発音産出・流暢性の総合訓練は姉妹アプリ English Listening Trainer と対面レッスンが担当。本アプリは単語・短フレーズ単位に特化する
