# 3b 語彙ブラウザ

索引: `docs/features/README.md`。共通シェル（`#vocabBtn` 起動元）は `docs/features/_common.md`。

## 観測可能挙動

- トップバー `#vocabBtn` から起動する exclusive full-page（`<section id="vocabPage">`、`body.vocab-page`）
- `navigate("vocab")` で起動。Back（`#vocabBackBtn`）は Menu と独立
- **Words のみ**（Phrases タブは Q6 で撤去済み。`renderVocabTab(tab)` は互換のため引数を受けるが常に `vocabTabCurrent="words"` に固定。`connected_speech.json` を使う Phrases 一覧 UI は現在存在しない）
- wordlist 全語（CEFR による絞り込みなし。3a のセッション CEFR 設定とは独立）。仮想化リスト・IPA 記号フィルタ（綴り検索なし）・A–Z ジャンプ・進捗チェック・CEFR バッジ
- IPA 記号ピッカー（`3c`）へは IPA フィルタバーの `.vocab-ipa-keyboard` から直接記号をタップ（別画面遷移ではなく同一 vocabPage 内のインライン UI）

## 画面構造

`#vocabPage`（`body.vocab-page`）

| 要素 | 内容 |
|------|------|
| ヘッダー | `.vocab-header.filter-bar-sticky`: Back（`#vocabBackBtn`）+ タイトル（`#vocabTitle`） |
| IPA フィルタバー | `.vocab-ipa-filter#vocabIpaFilterBar`: ラベル（選択アクセント + `(max 3)`）、選択記号チップ（`#vocabIpaChips`）、Accent toggle（`#vocabAccentToggle` GA/RP）、全消去ボタン（`#vocabIpaClear`、**通常非表示**）、IPA キーボード（`#vocabIpaKeyboard`、アクセント別記号セット） |
| A–Z ジャンプ | `.vocab-az-row`（`#vocabLetters`）+ ヒントテキスト（`#vocabAzHint`、`vocab.az.hint`） |
| 件数表示 | `#vocabCount`（フィルタなし: `vocab.count.all` / フィルタあり: `vocab.count.filtered`） |
| Words リスト（仮想化） | `#vocabBody`。`rebuildVirtSlots` / `paintVirtWindow`。常時 ~20–30 DOM 行、固定行高 + scroll、time-slicing なし。行: 上段 単語+CEFR バッジ（`.vocab-cefr-badge`） / 下段 GA+RP IPA（常に2行分の高さを予約）+gloss / 右端 進捗チェック+TTS |

### IPA 複合検索の挙動

IPA 記号ピッカー（3c）で選択した記号は `vocabIpaQuery` 配列に蓄積される。検索は**順序非依存の AND マッチ**（`vocabIpaQuery.every(sym => ipa.indexOf(sym) !== -1)`）。

- 全消去ボタン（`.vocab-filter-clear`）は**非表示**（`display:none!important`）。個別の toggle-off で操作する
- 記号の toggle-off: 既に選択済みの記号を再タップすると `vocabIpaQuery` から splice で除去
