# 3b 語彙ブラウザ

索引: `docs/features/README.md`。共通シェル（`#vocabBtn` 起動元）は `docs/features/_common.md`。

## 観測可能挙動

- トップバー `#vocabBtn` から起動する exclusive full-page（`<section id="vocabPage">`、`body.vocab-page`）
- hash: `#/vocab`（Words）/ `#/vocab/phrases`（Phrases）。Back（`#vocabBackBtn`）は Menu と独立
- Words: wordlist 全語。仮想化リスト・綴り検索・CEFR pills（初期全選択）・A–Z ジャンプ・進捗チェック・CEFR バッジ
- Phrases: `connected_speech.json` 全句。非仮想化。cs_type × level 順。CEFR バッジ
- IPA 記号ピッカー（`3c`）へは sticky filter の Segmented「IPA」から遷移

## 画面構造

`#vocabPage`（`body.vocab-page`）

| 要素 | 内容 |
|------|------|
| Sticky filter bar | `.filter-bar-sticky`: Back / タイトル、タブ（Words / Phrases）、Segmented 検索モード（綴り `#vocabSearchInput` / IPA → `3c`）、CEFR pills（複数選択・初期全選択）、A–Z ジャンプ |
| Words リスト（仮想化） | `rebuildVirtSlots` / `paintVirtWindow`。常時 ~20–30 DOM 行、固定行高 + scroll、time-slicing なし。行: 上段 単語+バッジ / 下段 GA+RP IPA+gloss / 右端 進捗チェック+TTS |
| Phrases リスト | 非仮想化 |
