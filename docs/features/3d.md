# 3d 学習状況

索引: `docs/features/README.md`。マーキング仕様は `docs/features/_common.md`。

## 観測可能挙動

- ヘッダー `#progressBtn`（`.topbar-btns` 内、`aria-label="学習状況"`）から `#/progress` へ遷移（2026-07-28 UI 改修でトップバー常設ボタンに変更。旧「1a の目的カード下『学習状況を見る』」導線は撤去済み）
- CEFR pills（A1/A2/B1/B2 + `all`）は複数選択。初期値は `prev_settings_v1.cefrLevels`、不在・空値時は A1+A2
- ドリル別（`2a`/`2b`/`2c`/`2d`）の卒業率カードのみを表示。**全体合算の進捗カードは 2026-07-28 phase-3 round-3 で削除済み**（「単に足し算/絞り込み変化で意味が薄い」— コード内コメント。DOM は残さず、`renderProgressPage()` 内の合算計算 `pct`/`graduated`/`total` は将来復活に備え計算のみ温存し、対応する `#progressOverallPct` 等の要素は null-safe で無視される）
- 卒業率算出: `ept_marks_v1` の値 3 を卒業として算出。`2a`–`2c` は wordlist、`2d` は `connected_speech.json` + `weak_forms.json` が母集団。母集団は CEFR pills の選択に連動してフィルタされる（`progressPoolForDrill`）
- **SRS queue（当日期限一覧・単語単位）は現行 DOM に存在しない**（旧仕様の「`ept_hist_v1` / `ept_vocab_v1` を統合した queue 表示 + 行タップで該当語 1 件の Study 開始」は撤去済み。localStorage キー自体は他機能で使用中の可能性があるが、3d 画面では参照されない）
- ドリル進捗カード（`.drill-progress-card`）をタップすると `openDrillProfile(drillId)` が呼ばれ、`3d` を離脱して `3a`（学習プロフィール、該当ドリル種別固定）に遷移する（該当語 1 件の Study 起動ではない）

## 画面構造

`#learningStatusPage`（`body.progress-page`、exclusive full-page）。Back（`#progressBackBtn`）/ Escape は元の画面（1a 等）へ戻る。

| 要素 | 内容 |
|------|------|
| ヘッダー | `.progress-header.filter-bar-sticky`: Back（`#progressBackBtn`）+ タイトル（`#progressTitle`） |
| CEFR フィルタ | `.progress-filters#progressFilters`: `.pill-cefr` × A1/A2/B1/B2 + `all`（`#progressCefrAll`）。複数選択 |
| ドリル進捗カードスタック | `.drill-progress-stack#drillProgressStack`。`2a`/`2b`/`2c`/`2d` の順で `.drill-progress-card`（`data-progress-drill="<id>"`）を描画。各カード: ドリル ID + タイトル（`drill.title.<id>`）、卒業率 `%`、progress meter、`progress.drill_summary`（卒業数/母集団）、マーク段階別カウント（`mark-slot-counts`: 0/1/2/3 の内訳） |
