# 3d 学習状況

索引: `docs/features/README.md`。マーキング仕様は `docs/features/_common.md`。

## 観測可能挙動

- `1a` の目的 4 カード下「学習状況を見る」から `#/progress` へ遷移
- CEFR pills は複数選択。初期値は `prev_settings_v1.cefrLevels`、不在・空値時は A1+A2
- 総合 / ドリル別の卒業率は `ept_marks_v1` の値 3 を卒業として算出。`2a`–`2c` は wordlist、`2d` は connected + weak が母集団
- SRS queue は `ept_hist_v1` / `ept_vocab_v1` を word 単位で統合し、早い dueAt を採用。当日末までを全件表示、100 件超は virtualization
- queue 行タップで該当語 1 件の `2c` Study を開始（通常の目的カード導線は不変）
