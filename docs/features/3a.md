# 3a 学習プロフィール

索引: `docs/features/README.md`。共通シェル・セッションフローは `docs/features/_common.md`。

## 観測可能挙動

- 目的カード選択後、毎セッション必ず `3a` を通過（Q-20-δ）。LocalStorage で前回設定をプリセット（`prev_settings_v1`）
- ユーザーは「そのまま『はじめる』」または変更後に開始を選べる
- 集約するパラメータ（Setup 11 項目（Accent 含む）+ Onboarding）: アクセント（GA/RP、セッション固定）、CEFR 複数選択（A1–B2）、目的別プリセット、旧「詳しい設定」相当。詳細な 11 項目の内訳は `docs/design/phase-1/screen-data-mapping.md` §1（正本）
- Language はヘッダー（`#langSwitcher` / `#langMenu`）に集約済み。独立の言語設定画面は廃止
- Connected（`2d`）フィルタ: level + type のみ（CEFR はタグ表示のみ）
- 学習中のアクセント切替 UI は持たない
