# 2a 音の発音を確かめる（Decode）

索引: `docs/features/README.md`。共通シェル・セッションフロー・適応出題・出題フィルタ定数は `docs/features/_common.md`。

## 観測可能挙動

- 目的: IPA を読んで、既知語の綴りに正しく対応できる力を鍛える
- IPA を提示 → 学習者が綴りを入力 → Check で判定
- 出題対象語: 機能語・不規則屈折・カジュアル表現を含む
- 音素フォーカス（主セレクタ）・綴りタイプ（従）でフィルタ（定数は `docs/features/_common.md` 出題フィルタ共通定数）
- 適応出題は localStorage 履歴とマーキングに基づく軽量 SRS（Leitner + 重み付け、詳細は `docs/features/_common.md`）
- GA / RP はプロフィール（`3a`）固定に追従（`activeIpa(c)`）

## 採点則・定数

| ok | bad |
|----|-----|
| 綴り（正規化後）完全一致 | それ以外 |

近似正解の判定（旧 Levenshtein ≤ 1 near、`lev` / `spellCheck` の near 分岐）は設計・実装とも削除済み。自己評価ボタンは設けない。
