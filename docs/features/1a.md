## 観測可能挙動

- エントリーポイント。目的 4 カードで即開始できる
- 目的カードタップ → `applyDrillId` → `3a` 学習プロフィールへ遷移（セッションフローは `docs/features/_common.md`）
- Hero 内リンクから `3h`「このアプリについて」（`#topSidebarLink`「思想を読む」→ `openAboutModal()`）と `IPA って何?`（`#topIpaLink` → `navigate("ipa")` → `#ipaInfoPage`）へ導線（2026-07-28: フッターから Hero へ移設）
- フッターは Feedback / Terms / Privacy のみ。`3h` / IPA / 言語設定への導線はフッターにはない（`docs/features/_common.md` Footer 参照）
